Content-aware image resizing for Apple platforms

SeamCarvingSwift is a modular seam-carving package with a platform-independent Core engine, optional Accelerate and Metal backends, Apple image bridges, Vision face protection, a command-line tool, and one SwiftUI app target for iPhone, iPad, and Mac Catalyst.

What is implemented

The engine supports shrink and enlarge operations, backward Sobel and forward-luma energy, sequential seam edits, protection and removal masks, object removal with optional restoration, progress and cancellation, optional Lanczos residual pre-scaling, and CPU/Accelerate/Metal selection through the Apple facade.

Vision face protection and Metal are optional platform adapters. Automatic backend selection tries Metal, then Accelerate, then CPU. Debug seam artifacts intentionally use CPU observation. See limitations before assuming every backend has identical performance characteristics.

Verification status

The repository records package, simulator, Catalyst, and signed iPad unit-test results in the capability matrix. Physical iPad UI XCTest currently times out while enabling automation mode before a UI test method runs; iPad Simulator is the passing UI-automation environment. Physical Metal screening is recorded separately and should be rerun with a dedicated signed Metal host when release evidence is required.
