命令行

seamcarve-cli

macOS 可执行文件，用于内容感知图像缩放。参数语法由 Swift Argument Parser 处理，图像处理、批量调度和退出码由 SeamCarvingCLI 负责。

构建和查看帮助

swift build --product seamcarve-cli
swift run seamcarve-cli --help

当前 executable 因依赖 Core Graphics、ImageIO 和 URLSession 图像 I/O 而面向 macOS。实际参数以 --help 和 Sources/SeamCarvingCLI/CLIArgumentParser.swift 为准。

调用方式

seamcarve-cli INPUT OUTPUT --width PIXELS --height PIXELS
seamcarve-cli INPUT OUTPUT --percentage PERCENT
seamcarve-cli INPUT OUTPUT --square
seamcarve-cli --input-dir INPUT_DIR --output-dir OUTPUT_DIR \
  --width PIXELS --height PIXELS

INPUT 可以是本地路径、明确的 http(s) URL 或 stdin 的 -；OUTPUT 可以是本地路径或 stdout 的 -。必须且只能选择 exact、percentage、square 三种 resize mode 之一。

主要参数

参数取值/行为
--width/--height正数目标尺寸，必须成对出现。
--percentage P相对源图比例；大于 100 放大，小于 100 缩小，每个轴至少为 1。
--square使用源图短边作为正方形边长。
--backendautomatic、cpu、accelerate、metal。
--energybackward 或 forward。
--orderwidth-first、height-first、adaptive。
--pre-scalenone 或 lanczos-residual。
--deterministic使用可复现的 backend 行为。
--blur-radius/--sobel-threshold仅 backward Sobel 的 blur 和 threshold 控制。

blur/threshold 不能和 --energy forward 同时使用。开启 debug 并选择 Metal/automatic 时，为了 seam observation 会降级为 CPU。

Mask 和人脸保护

seamcarve-cli input.png output.png --width 900 --height 600 \
  --protect-mask subject-mask.png --protect-strength hard
seamcarve-cli portrait.jpg output.jpg --percentage 80 \
  --face-policy caire --face-cadence once
  • mask 必须与输入尺寸一致；强度取解码图像 RGB 最大通道并归一化到 0...1。
  • --protect-strength hard|soft，soft 使用 --protect-weight（默认 1000）。
  • --removal-weight 默认 1000；remove mask 会降低标记像素的 seam 代价。
  • --face-policy caire|vision，cadence 为 once 或 each-pass。
  • 批量模式不支持单文件 mask。

格式、stdin/stdout 和 debug

seamcarve-cli input.png output.jpg --width 800 --height 600
seamcarve-cli input.png result.data --width 800 --height 600 --format bmp
cat input.png | seamcarve-cli - - --width 800 --height 600 --format png > result.png
seamcarve-cli input.png output.png --width 800 --height 600 \
  --debug --debug-directory debug-seams --seam-color '#ff0066cc' \
  --seam-shape line

格式支持 PNG、JPEG/JPG、BMP；显式 --format 覆盖扩展名。输出为 - 时 stdout 只有图像二进制，summary、进度、错误都在 stderr。debug 目录包含 manifest.json 和每条 seam 的 PNG overlay；Metal debug 会使用 CPU。

批处理

seamcarve-cli --input-dir photos --output-dir resized \
  --percentage 80 --concurrency 4
seamcarve-cli --input-dir photos --output-dir resized \
  --width 1200 --height 800 --recursive --concurrency 2

批量目录必须是本地目录；支持 PNG、JPG/JPEG、BMP。任务按相对路径排序，默认并发 2；递归时保留子目录。显式 format 会将输出扩展名改成 .png、.jpg 或 .bmp。单个任务失败会计入最终 summary，任何失败都会返回 data-error。

退出码

码含义常见原因
0success完成。
64usage参数错误、冲突、缺少 resize mode 或不兼容配置。
65data error输入/mask 解码失败、尺寸不符、格式不支持或写出失败；批量有失败任务也使用该码。
70software error未预期的处理错误。
130cancelled取消，等于 128 + SIGINT。

管道场景不要把 stderr 合并到 stdout，否则会污染图像二进制。
