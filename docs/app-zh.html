SwiftUI App 使用指南

App 使用一个 SeamCarvingApp target 和共享 SwiftUI 源码，覆盖 iPhone、iPad 与 Mac Catalyst。布局会从 iPhone 的紧凑导航栈自适应为 iPad 和 Catalyst 的侧栏/详情结构。

构建和运行

Xcode 项目由 Apps/SeamCarvingApp/project.yml 生成。生成后的 project 被 Git 忽略，修改 YAML 后请重新生成。

cd Apps/SeamCarvingApp
xcodegen generate
xcodebuild -project SeamCarvingApp.xcodeproj -scheme SeamCarvingApp \
  -destination 'generic/platform=iOS' build
xcodebuild -project SeamCarvingApp.xcodeproj -scheme SeamCarvingApp \
  -destination 'platform=macOS,variant=Mac Catalyst' \
  CODE_SIGNING_ALLOWED=NO build

运行真机时，为 App、单元测试和 UI 测试 target 选择 Apple Development Team。个人 Team 可能需要 Xcode 为每个测试 bundle 创建 provisioning profile。

基本流程

  1. 导入。 在 iPhone、iPad 和 Catalyst 上选择 Photos 或 Files…，模型会把图像解码为规范 RGBA8 像素。
  2. 设置目标尺寸。 修改 Target width 和 Target height；需要两个字段联动时启用 Lock aspect ratio。
  3. 选择算法。 选择 Backward Sobel 或 Forward Luma，再选择 Width then Height、Height then Width 或 Adaptive。
  4. 选择后端。 Automatic 会尝试 Metal、Accelerate、CPU。Deterministic 使用可复现的 CPU 行为。None 保持精确 seam 语义；Lanczos + exact residual 是显式选择的 Apple-only 近似模式。
  5. 绘制 mask。 使用 Protect、Remove 或 Erase，调整 Brush size 和 Strength，并按需使用 Undo、Redo、Clear masks、Reset masks。
  6. 保护人脸。 开启 Face protection，选择 Caire-inspired 或 Vision quality，选择 Detect once 或 Re-detect each pass，调整 confidence/expansion，并可排除检测区域。
  7. 调整并导出。 点击 Resize；进行中的任务会提供取消和进度。选择 PNG 或 JPEG，点击 Export image 后使用平台分享面板或文件目的地。

平台行为

平台布局与输入说明
iPhone紧凑导航栈；画布与控制项纵向滚动。Photos 和 Files 导入使用 iOS API。
iPad常规导航 split view，侧栏放控制项、详情区放画布；已声明所有界面方向。模拟器 UI automation 是可靠的 UI 测试环境。
Mac Catalyst同一个 iOS target 使用常规侧栏/详情布局运行。签名运行需要有效的 Apple Development identity；没有独立的原生 AppKit target。

共享控件使用明确的 disabled-state 颜色，确保深色模式下 Export image 和 Resize 仍可读。通过 Xcode 启动 Catalyst 时，LaunchServices 或 ViewBridge 等 macOS/Xcode 服务诊断可能仍会输出，但不代表 App 功能失败。

测试状态与限制

验收记录维护在能力矩阵中。

  • iPhone/iPad 模拟器：记录中的回归包含 31 个单元测试和 2 个 UI 测试，均通过。
  • Mac Catalyst：干净构建和 31 个单元测试通过；签名 Catalyst UI runner 是否可用取决于本机 Mac Development identity。
  • iPad 真机：使用个人开发 profile 完成 App/测试宿主签名、安装和 31 个单元测试。
  • iPad 真机 UI XCTest：runner 在执行任何 UI 测试方法之前，启用 automation mode 时超时。这被记录为设备/XCTest 服务限制，不算 UI 测试通过。
  • Metal：已有 package parity 测试和此前签名真机 16/16 screening；新的 release benchmark 仍需要专用的签名 Metal test host。

故障排查

  • 找不到项目：在该目录执行 xcodegen generate。
  • 签名失败：为 App、单元测试和 UI 测试 target 配置相同 Team 与自动签名，不要提交本地 provisioning 设置。
  • 导入失败：确认选中的是图像文件，并授予 Photos/Files 权限。
  • iPad UI automation 超时：重启 Xcode 和设备，使用 USB 并解锁设备，单独重试 UI target；真机 runner 仍无法启用 automation 时，使用 iPad 模拟器完成自动化 UI 验收。
  • 控制台噪声：LSPrefs、FSFindFolder、ViewBridge、task-port 等信息通常是 macOS/Xcode 诊断；如果 App 正常运行，不应通过添加危险 entitlement 处理。
