Apple 平台的内容感知图像缩放

SeamCarvingSwift 是一个模块化 seam carving 项目：包含平台无关的 Core 引擎、可选 Accelerate/Metal 后端、Apple 图像桥接、Vision 人脸保护、命令行工具，以及一套同时运行在 iPhone、iPad 和 Mac Catalyst 的 SwiftUI App。

了解 Core、Accelerate、Metal、Apple、Vision、CLI 和 SwiftUI App 的职责与依赖。

算法原理

了解能量函数、动态规划、mask、放大和 Metal fallback 策略。

Swift API

从 RGBA8 数据开始，逐步加入 Apple 图像、mask、进度、取消和 Vision。

命令行

使用真实的 seamcarve-cli 参数处理单文件、流和批量任务。

Apple App

在 iPhone、iPad、Mac Catalyst 上导入、绘制 mask、人脸保护、缩放和导出。

查看当前 Caire 对齐能力和真实验收状态。

快速开始

git clone <repository-url>
cd SeemCarvingSwift
swift test
swift run seamcarve-cli --help

文档站点没有 Node、Python、Jekyll 或 MkDocs 构建依赖，GitHub Pages 可以直接发布提交到仓库的 docs/ 目录。

已实现能力

引擎支持缩小与放大、backward Sobel 和 forward-luma 能量、逐条 seam 编辑、保护/移除 mask、对象移除及可选恢复原尺寸、进度与取消、可选 Lanczos residual 预缩放，以及通过 Apple facade 选择 CPU/Accelerate/Metal。Vision 人脸保护和 Metal 都是可选适配器。

验证状态

包测试、模拟器、Catalyst 和 iPad 真机单测记录在能力矩阵中。iPad 真机 UI XCTest 目前在启用 automation mode 前超时，没有执行到 UI 测试方法；iPad 模拟器是当前通过 UI 自动化验收的环境。真机 Metal 的历史 16/16 screening 另有记录，发布前应使用专用签名 Metal host 重跑。
