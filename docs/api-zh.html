Swift API

已有 canonical RGBA8 像素时使用 Core；外部图像类型只导入其所属 adapter。

模块选择

图像/API导入
RGBA8Image 和 CPU 参考 APISeamCarvingCore
Apple 后端选择、CGImage、CIImageSeamCarvingApple（v2 兼容 facade），或 SeamCarvingAppleRuntime + SeamCarvingAppleImaging
CVPixelBufferSeamCarvingCoreVideo
UIImageSeamCarvingUIKit
NSImageSeamCarvingAppKit

Core

import SeamCarvingCore
let image = try RGBA8Image(width: 4, height: 4, pixels: rgbaBytes)
let result = try await SeamCarver().resize(image, to: try PixelSize(width: 3, height: 4))

CGImage / CIImage 兼容 facade

import CoreGraphics
import SeamCarvingApple
let carver = try AppleSeamCarver(configuration: .init(backend: .automatic))
let output: CGImage = try await carver.resize(inputCGImage, toPixelSize: target)

facade 只 re-export Runtime 和 Imaging，保留 RGBA8、CGImage、CIImage API；不再导出 CVPixelBuffer、UIImage、NSImage overload。

显式平台 adapter

import SeamCarvingApple // Runtime + Imaging 兼容 facade
import SeamCarvingUIKit // iOS/iPadOS/Catalyst 的 UIImage
// 或改为 SeamCarvingAppKit（NSImage）/ SeamCarvingCoreVideo（CVPixelBuffer）。

adapter 会先把外部像素标准化成 upright、origin-zero、straight-alpha RGBA8，再调用 runtime。人脸保护仍是可选的 SeamCarvingVision。

平台状态

Core 有 macOS/Linux/Windows 的 CI build/test gate。Wasm 和 Android 尚不是已实现的 product，只预留了未来 bridge 使用的 RGBA8 adapter 边界。
