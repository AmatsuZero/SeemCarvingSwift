集成指南

Swift API

已有 canonical RGBA8 像素时使用 Core；从 CGImage 等 Apple 图像开始时使用 Apple facade；需要人脸保护时再加入 Vision。

包和平台

Package 使用 Swift tools 6.0，平台下限是 iOS 17 和 macOS 14。Core、Accelerate、Metal、Apple、Vision、CLI 和 benchmark 都是独立 product。Core-only 不导入 Apple framework。

import SeamCarvingCore

let image = try RGBA8Image(width: 4, height: 4, pixels: rgbaBytes)
let target = try PixelSize(width: 3, height: 4)
let result = try await SeamCarver().resize(image, to: target)

RGBA8Image 要求正尺寸和恰好 width * height * 4 个 row-major RGBA 字节。

Apple facade

适用：SeamCarvingApple，Apple 平台。

import SeamCarvingApple
import SeamCarvingCore

let carver = try AppleSeamCarver(configuration: .init(
    backend: .automatic, metalMode: .full, deterministic: false
))
let output = try await carver.resize(
    inputCGImage,
    toPixelSize: try PixelSize(width: 1200, height: 800),
    options: .init(energyMode: .forwardLuma)
)

Apple facade 还提供带 orientation 的 CIImage/CVPixelBuffer overload、UIKit 的 UIImage overload，以及非 Catalyst AppKit 的 NSImage overload。

ResizeOptions

属性取值/含义
energyMode.backwardSobel 或 .forwardLuma
dimensionOrder.widthThenHeight、.heightThenWidth、.adaptiveNormalizedCost
masksMaskPair，含保护层、remove mask 和 removal weight
preScaleStrategy默认 .none，或 Apple-only .lanczosThenExactResidual
blurRadius/sobelThreshold只作用于 backward Sobel；0 保持默认结果
progress每次提交 seam 后回调 ResizeProgress
seamObserver可抛错的 seam 观察 hook；抛 CancellationError 会在应用前停止

Mask、对象移除和取消

let protect = try Mask(width: 4, height: 4, values: protectValues)
let remove = try Mask(width: 4, height: 4, values: removeValues)
let masks = try MaskPair(
    protectionLayers: [try ProtectionLayer(mask: protect, strength: .soft(1_000))],
    removal: remove,
    removalWeight: 1_000
)
let output = try await SeamCarver().removeObject(
    from: image, removalMask: remove,
    restoreOriginalSize: true,
    options: ResizeOptions(masks: masks)
)

Mask 值在 0...1；hard protection 让像素不可选，soft protection 增加代价，remove 减少代价。resize 是 async，可保存 Task 并调用 cancel()；进度含完成编辑数、总编辑数和当前尺寸。

Vision 人脸保护

import SeamCarvingVision

let faceCarver = try FaceAwareSeamCarver(
    configuration: .init(backend: .automatic),
    detector: try VisionFaceDetector(),
    policy: .caireInspired(try CaireInspiredParameters(
        expansionFraction: 0.10,
        protectionWeight: 1_000,
        minimumConfidence: 0.5
    )),
    cadence: .detectOnceAndTransformMask
)
let output = try await faceCarver.resize(
    inputCGImage, orientation: .up, toPixelSize: target
)

也可以使用 VisionQualityParameters。.redetectEveryPass 目前只支持 seam removal，不支持 enlargement。这里的 Caire-inspired 是 mask 策略，不是 detector 兼容。

API 限制

  • Core 不知道 UIKit、AppKit、Core Image、Vision 或 Metal。
  • Metal 不保证 enlargement、adaptive order 或所有方向都只在 GPU 运行。
  • 精确逐 seam 是默认；Lanczos residual 是显式 Apple-only 近似。
  • 人脸 redetect cadence 不支持放大。
