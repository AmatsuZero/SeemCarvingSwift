Project map

Capability-based architecture

Algorithms remain in a portable Core. Optional computation and host-image adapters depend inward; Core never depends on them.

Boundary rules

Core has no Apple graphics/media/compute imports or platform conditionals. Runtime contains backend capability selection, not image types. UIKit and AppKit are separate targets; each may use only one whole-file own-framework compile guard so SwiftPM can discover it on incompatible hosts. No adapter mixes UIKit/AppKit or contains Catalyst-specific behavior branches.

Future hosts

Wasm, Android and Windows adapters should translate their host buffers to RGBA8Image and depend only on Core (plus an explicit runtime if needed). They are not currently implemented products. The Core CI matrix is the verification gate for cross-host portability.
