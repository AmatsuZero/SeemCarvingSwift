Integration guide

Swift API

Use the portable Core API for canonical RGBA8 pixels; add only the adapter product that owns the external image type.

Module selection

Portable Core

import SeamCarvingCore
let source = try RGBA8Image(width: 4, height: 4, pixels: rgbaBytes)
let target = try PixelSize(width: 3, height: 4)
let result = try await SeamCarver().resize(source, to: target)

CGImage and CIImage compatibility facade

import CoreGraphics
import SeamCarvingApple
let carver = try AppleSeamCarver(configuration: .init(backend: .automatic))
let output: CGImage = try await carver.resize(inputCGImage, toPixelSize: target)

The facade re-exports Runtime and Imaging only. It preserves RGBA8, CGImage and CIImage APIs; it does not export CVPixelBuffer, UIImage or NSImage overloads.

Explicit platform adapters

import SeamCarvingApple // Runtime + Imaging compatibility facade
import SeamCarvingUIKit // UIImage overloads on iOS/iPadOS/Catalyst
// Or use SeamCarvingAppKit for NSImage, or SeamCarvingCoreVideo for CVPixelBuffer.

All adapters normalize external pixels into upright, origin-zero, straight-alpha RGBA8 before calling the runtime. Vision remains optional through SeamCarvingVision.

Platform status

Core has a macOS/Linux/Windows CI build-and-test gate. Wasm and Android are not implemented products yet; the RGBA8 adapter boundary is reserved for their future bridges.
