Integration guide

Swift API

Use Core when you already have canonical RGBA8 pixels. Use the Apple facade when your application starts with CGImage or another Apple image type. Add Vision only when face-aware protection is needed.

Package and platform setup

The package uses Swift tools version 6.0, supports iOS 17 and macOS 14, and exposes separate products for Core, Accelerate, Metal, Apple, Vision, CLI, and benchmark consumers.

// Package.swift
dependencies: [
    .package(url: "https://github.com/apple/swift-argument-parser.git", from: "1.6.0")
],
targets: [
    .target(name: "MyImageTool", dependencies: [
        .product(name: "SeamCarvingCore", package: "SeamCarvingSwift")
    ])
]

Core-only code needs no Apple framework. SeamCarvingApple and SeamCarvingVision are Apple-platform products; Vision also links the Vision framework.

Core: canonical RGBA8 resize

Availability: SeamCarvingCore; platform independent.

import SeamCarvingCore

let source = try RGBA8Image(
    width: 4,
    height: 4,
    pixels: rgbaBytes // width * height * 4 bytes, row-major RGBA
)
let target = try PixelSize(width: 3, height: 4)

var options = ResizeOptions(
    energyMode: .backwardSobel,
    dimensionOrder: .widthThenHeight
)
options.progress = { progress in
    print("\(progress.completedEdits)/\(progress.totalEdits) \(progress.size.width)x\(progress.size.height)")
}

let result = try await SeamCarver().resize(source, to: target, options: options)

RGBA8Image validates positive dimensions and exact pixel count. Use RGBA8 and RGBA8Image.solid(width:height:color:) for small fixtures.

Apple facade: CGImage and backend selection

Availability: SeamCarvingApple; Apple platforms.

import CoreGraphics
import SeamCarvingApple
import SeamCarvingCore

let target = try PixelSize(width: 1200, height: 800)
let carver = try AppleSeamCarver(configuration: .init(
    backend: .automatic,
    metalMode: .full,
    deterministic: false
))
let output: CGImage = try await carver.resize(
    inputCGImage,
    toPixelSize: target,
    options: .init(energyMode: .forwardLuma)
)

The facade also has overloads for CIImage and CVPixelBuffer with an explicit orientation, UIImage on UIKit platforms, and NSImage on native AppKit (not Mac Catalyst). It normalizes input into the Core coordinate system before carving.

Resize options

PropertyValues / meaning
energyMode.backwardSobel or .forwardLuma.
dimensionOrder.widthThenHeight, .heightThenWidth, or .adaptiveNormalizedCost.
masksA MaskPair with protection layers, optional removal mask, and removal weight.
preScaleStrategy.none by default, or Apple-only .lanczosThenExactResidual.
blurRadius / sobelThresholdBackward-Sobel-only controls; zero preserves the default behavior.
progressAn optional @Sendable callback after each committed edit.
seamObserverAn optional throwing hook for seam observations. Throwing CancellationError stops before that seam is applied.

Protection and removal masks

Mask is a row-major Float plane with values in 0...1. A hard layer makes marked pixels effectively unavailable; a soft layer adds a non-negative weighted cost. Removal subtracts its weight and protection takes precedence on overlap.

let protect = try Mask(width: 4, height: 4, values: protectValues)
let remove = try Mask(width: 4, height: 4, values: removeValues)
let layers = [try ProtectionLayer(mask: protect, strength: .soft(1_000))]
let masks = try MaskPair(
    protectionLayers: layers,
    removal: remove,
    removalWeight: 1_000
)
let options = ResizeOptions(masks: masks)
let result = try await SeamCarver().resize(source, to: target, options: options)

Object removal and restoration

Availability: Core and its backend contract.

let result = try await SeamCarver().removeObject(
    from: source,
    removalMask: objectMask,
    restoreOriginalSize: true,
    options: ResizeOptions(masks: try MaskPair(
        protectionLayers: [],
        removal: objectMask,
        removalWeight: 1_000
    ))
)

The removal workflow chooses seams that cross the marked object, updates all masks with every edit, and optionally resizes back to the source size.

Progress and cancellation

Resize methods are async and cooperate with Swift task cancellation. Keep the task and call cancel(); the engine checks cancellation between edits. Progress reports completed edits, total edits, and the current PixelSize.

let task = Task {
    try await SeamCarver().resize(source, to: target, options: .init(
        progress: { progress in
            progressView.update(progress)
        }
    ))
}
// Later, from the owning operation:
task.cancel()

Face protection with Vision

Availability: SeamCarvingVision and Apple platforms. The detector is Apple Vision; the policy names describe mask behavior and do not promise Caire/Pigo compatibility.

import SeamCarvingApple
import SeamCarvingCore
import SeamCarvingVision

let detector = try VisionFaceDetector()
let policy = FaceProtectionPolicy.caireInspired(
    try CaireInspiredParameters(
        expansionFraction: 0.10,
        protectionWeight: 1_000,
        minimumConfidence: 0.5
    )
)
let faceCarver = try FaceAwareSeamCarver(
    configuration: .init(backend: .automatic),
    detector: detector,
    policy: policy,
    cadence: .detectOnceAndTransformMask
)
let output = try await faceCarver.resize(
    inputCGImage,
    orientation: .up,
    toPixelSize: target
)

Use VisionQualityParameters when the 0.20 expansion and feathering policy is preferred. .redetectEveryPass reruns face detection for each removal pass and currently rejects enlargement.

Find a seam without resizing

The Apple facade exposes findSeam(in:orientation:options:) for diagnostics and planning. The returned SeamPath contains vertical or horizontal orientation, one coordinate per row/column, and the total cost.

let seam = try await carver.findSeam(
    in: inputCGImage,
    orientation: .vertical,
    options: .init(energyMode: .backwardSobel)
)
print(seam.orientation, seam.coordinates, seam.totalCost)

API limitations

  • Core intentionally knows nothing about platform image types or Vision.
  • Metal is optional and does not make enlargement, adaptive ordering, or every orientation GPU-only.
  • Exact sequential carving is the default. Lanczos residual mode is an explicit Apple-only approximation.
  • Face redetection cadence supports seam removal only; use detect-once for enlargement.
  • For current symbols and availability, treat the source declarations in Sources/ as canonical; this page avoids undocumented convenience APIs.
