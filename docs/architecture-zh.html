项目地图

项目架构

依赖方向是单向的：Core 定义图像和 seam 语义，Apple facade 负责图像转换与后端选择，Vision 是可选适配器，CLI 和 App 是消费者。

模块分层

01 · 核心引擎

SeamCarvingCore

图像值、mask、能量、动态规划、seam 编辑、规划器和 CPU 参考行为。

depends on: 无

02 · 后端实现

SeamCarvingAccelerate

Accelerate 能量和 seam 操作。

depends on: Core

SeamCarvingMetal

可选 Metal 后端和 shader 资源。

depends on: Core

03 · Apple 平台适配器

SeamCarvingApple

depends on: Core + Accelerate + Metal

SeamCarvingVision

Vision 人脸检测和保护 mask 组合。

depends on: Core + Apple

↓

04 · 产品消费者

SeamCarvingCLI

CLI library 和 seamcarve-cli 可执行文件。

depends on: Core + Apple + Vision

SwiftUI App

depends on: Core + Apple + Vision

图像数据流

  1. Apple bridge 将外部图像按 orientation 转成 upright 的 canonical RGBA8。
  2. Core 接收 RGBA8、PixelSize、ResizeOptions 和可选 mask。
  3. 规划器决定 width/height 顺序，每次重建能量和 mask 调整。
  4. 后端逐条寻找并编辑 seam；提交后回调进度，在 seam 之间检查取消。
  5. Apple bridge 编码结果；CLI 再写出 PNG、JPEG 或 BMP。

并发与内存

Core API 使用 async/Sendable 方向；CPU 使用 Float32 行和 parent/index buffer。Metal completion 通过 checked continuation 等待，不阻塞 main actor。App 由一个 resize task 负责新任务，并取消旧任务。

Backend SPI 面向内部验证。普通调用方应使用 SeamCarver 或 AppleSeamCarver，而不是直接实现 backend protocol。
